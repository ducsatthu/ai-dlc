One-line: the console's action control — use `primary` (amber) only for the decision a human must make, `ok`/`danger` for approve/reject pairs.

```jsx
<Button variant="ok" size="sm">Approve</Button>
<Button variant="danger" size="sm">Reject</Button>
<Button variant="ghost" size="sm">Cần thảo luận</Button>
```

Variants: primary · secondary · ghost · danger · ok. Sizes sm/md/lg. `full` stretches. Labels are uppercase mono; keep them short and Vietnamese where the UI is Vietnamese.
