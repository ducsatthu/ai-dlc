One-line: tiny mono status token used for the 8 stage steps, task statuses and filters.

```jsx
<Chip tone="done">1</Chip><Chip tone="active">5 ◇D</Chip><Chip>6</Chip>
```

Colour semantics are fixed system-wide: green = done/approved, amber = waiting on a human, blue = agent activity, grey outline = pending.
